# Poređenje algoritama sortiranja

Maturski rad: Windows Forms aplikacija (C#, .NET 6) koja generiše niz zadate dužine i poredi brzinu algoritama sortiranja:

- Bubble sort
- Selection sort
- Insertion sort
- Merge sort
- Quick sort

## Pokretanje

Otvoriti `PoredjenjeSortAlgoritama.sln` u Visual Studio i pokrenuti projekat.
